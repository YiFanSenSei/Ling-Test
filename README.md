## 一、作品简介

「匠作」是一座可以走进去的中国非物质文化遗产数字展馆。

它不试图做一份资料汇编，而是一次「重新介绍」的尝试：把名录里那些只剩一个名字的手艺，重新讲成有人、有工序、有温度的事。

全站以国家级非物质文化遗产代表性项目为内容，收录 **3,614 条**按申报地区拆分的子项记录，覆盖 **十大类别**、**33 个省级行政区**与 **五批**公布年表。其中 **150 个**项目建立了完整详情页，含官方项目介绍正文与国家级代表性传承人档案；站内另为 **379 位**传承人建立了可检索、可逐人翻阅的独立档案页。

此外，本站把三门手艺做成了可交互的体验：**苏绣的针法、宣纸的捞纸工序、榫卯的咬合**。目的很简单——让「非遗」这两个字从名词变成动词。

### 六个页面

| 页面 | 路径 | 内容 |
|---|---|---|
| 首页 | `#/` | 序章、数据看板、门类十方、精选馆藏、技艺体验、五批年表与地域分布 |
| 非遗名录 | `#/gallery` | 3,614 条子项的全量检索与筛选（门类 / 批次 / 地区），结果同步到 URL |
| **传承人** | `#/inheritors` | 379 位国家级代表性传承人，可按门类筛选、按出生年份或姓氏排序 |
| 传承人档案 | `#/inheritor/:id` | 单人生平、官方编号、所属项目，以及同一手艺的其他传承人 |
| 技艺体验 | `#/simulator` | 苏绣（平针 / 打籽）、宣纸（捞纸帘纹）、榫卯（燕尾直角）三门模拟器 |
| 关于本站 | `#/about` | 作品说明、数据来源与统计口径、第三方资源声明、技术实现规格 |

### 检索设计

名录与传承人两页的检索都做了**同义词扩展**：官方项目名用的是行业术语，而访客按日常叫法来搜，因此「瓷器」会自动一并联查「瓷」、「丝绸」联查「丝 / 锦 / 绸」、「玉器」联查「玉雕」。实测「瓷器」由 0 条提升到 38 条，「丝绸」由 1 条提升到 59 条，且逐条核对无伪命中。

对于「戏曲」「音乐」这类**指向整个门类**的词，程序不会假装它们能当关键词用，而是识别出来并提示「你要找的是一个门类」，同时给出通往该门类筛选的按钮——把控制权交回访客，而不是丢给他一堆沾边的结果。

### 形态

数字展馆 + 技艺互动体验（网页设计比赛主题二「匠心传承，非遗焕新」）

## 三、非自写库及用途声明

按比赛要求逐项注明第三方库的名称与用途：

| 名称 | 性质 | 用途 | 是否影响评分的制作难度 |
|---|---|---|---|
| Vite | 构建工具（开发期） | 模块打包与开发服务器。构建产物为原生 HTML / CSS / JavaScript，运行时**不加载任何框架**。 | 否，仅用于打包，不参与页面呈现 |
| — | 无其他第三方依赖 | 无 UI 组件库、无 CSS 框架、无图标库、无动画库、无外部字体文件。所有图形（纹样、徽记、模拟器画面）均为程序化绘制或内联 SVG。 | — |

**说明**：本站为纯静态前端作品，不含任何服务端逻辑。全部代码由团队手写，未使用任何 UI 框架与预设样式库。Vite 只在开发阶段用于打包，构建产物是**一个自包含的 HTML 文件**（JavaScript、CSS 与三个数据文件全部内联），评委双击「打开作品.html」即可运行，无需安装任何依赖、无需联网加载资源。

> 关于这一步为什么必要：Chrome 自 2021 年起禁止 `file://` 页面加载 `<script type="module">`，也禁止其用 `fetch` 读取同目录 JSON（跨源策略，本地页面的 origin 为 `null`）。因此「外链 JS + 外链数据」的常见产物，评委双击后只会停在加载画面上。我们把全部资源内联进单个 HTML，并且改成普通 `<script>`（非 module），从根上避免了这两条限制。此行为已在真实浏览器中以 `file://` 协议完整回归验证：九个路由与三项交互全部正常，控制台零报错、零网络请求失败。

## 四、界面规格与技术实现

| 项目 | 说明 |
|---|---|
| 界面规格 | **1440 × 900**（比赛要求三选一；已在页面 `<meta name="design-spec">`、页脚与「关于本站」页三处标注） |
| 自适应 | 响应式布局，覆盖 1920 / 1440 / 720 三档及移动端（390）、平板（834）。实测 25 个「规格 × 页面」组合，横向溢出均为 0。 |

## 六、数据来源与统计口径

本站数据抓取自 **中国非物质文化遗产网 · 中国非物质文化遗产数字博物馆**（中华人民共和国文化和旅游部主管，中国艺术研究院主办）。

| 指标 | 官方公布 | 本站收录 |
|---|---|---|
| 国家级代表性项目 | 1,557 项 | —（不重复统计） |
| 按申报地区拆分的子项 | 3,610 条 | 3,614 条 |
| 国家级代表性传承人 | 3,998 位 | 379 位已建档 |
| 列入联合国教科文组织名录 | 45 项 | —（未单独建页） |
| 公布批次 | 5 批 | 5 批（完整） |

**关于两个不同数字**：官方公布的「国家级代表性项目 1557 项」是**项目数**；本站收录的 3,614 条是按申报地区拆分后的**子项记录**。同一个项目若由多个地区共同申报，会拆成多行记录。例如「剪纸」是一个项目，但蔚县剪纸、扬州剪纸、傣族剪纸等地子项会分别列出。两者是不同层级的统计口径，因此本站检索使用子项数据，展示项目总数时使用官方口径，并在页脚同时标注。

抓取过程中剔除了混入的其他目录数据（如「第一批国家传统工艺振兴目录」）共 383 条，其详情页标题不属于国家级非遗名录体系，已通过项目编号格式与详情页标题双重校验。

**关于传承人档案中的空缺**：379 位传承人中，258 位有明确出生日期、311 位有官方编号。其余空缺**不是抓取遗漏**——官方网站在第五批（2021 年公布）传承人的公开表格中，本身就没有标注编号与出生日期。本站照实留空并显示为「—」，不作任何推测性填补。档案的价值在于可信，而不在于看起来完整。

## 七、关于素材

本站**未使用任何来源不明的网络图片**。打开名录你会发现，每个项目卡片上没有照片，而是一门类别徽记与一套几何纹样。

这是一个刻意的选择。官方公开数据并不附带可自由使用的项目配图，而随手拿来的低分辨率网图，既不尊重这些手艺，也对不起观众的信任。与其如此，不如把「没有照片」做成一套自治的视觉语言：十大类别各有专属纹样，由 SVG 绘制，可无损缩放、零加载开销，也不存在版权问题。

技艺体验部分的画面（绣布、纸浆、木料）同样是程序化绘制的，颜色取自真实材料的取样，而非贴图。

## 八、本地运行

```bash
# 安装依赖
pnpm install

# 开发预览（http://localhost:5173）
pnpm dev

# 构建：产物为单个自包含文件 dist/index.html，双击即可打开
pnpm build
```

构建脚本会自动把 JS、CSS 与三个数据文件内联进 `dist/index.html`，
并自检产物中不含被误切的 HTML 片段，确保双击可用。

数据抓取脚本（需联网，仅开发期使用）：

```bash
node scripts/fetch-data.mjs      # 抓取名录列表
node scripts/fetch-details.mjs   # 抓取核心项目详情
```
